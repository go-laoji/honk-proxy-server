# 服务商节点按 IP 归属地入组

对应 [Issue #48](https://github.com/go-laoji/honk-proxy-server/issues/48)，基于 `feature/node-ip2region`。

- 对服务商返回的公网端点 IP 使用本地 ip2region 分类。分类随租约进入动态池。服务启动、再次提取和更新地区库时重新计算。保留现有租约数据、来源指纹、健康检查及短租约准入。
- 在目标代理组添加服务商地区规则。每条规则限定一个服务商，至少选择运营商、省份、城市中的一项。同一规则的条件须全部匹配，多条规则任一匹配即可。可加入多个组。现有显式成员、来源、子组、过滤及固定节点策略继续按原语义执行。
- 供应商详情提供地区规则编辑区，可从租约带入条件、选择已有分组或新建目标组。保存复用配置版本校验与热应用。租约表展示分类依据，节点库存支持按目标组查阅。
- 验证新提取和已有租约、规则热更新、数据库换版、缺失地区、嵌套组及选点一致性。页面验证使用回环服务和独立状态目录，所有开发进程启用 `HPS_FORBID_HOST_NETWORK_CHANGES=1`。
