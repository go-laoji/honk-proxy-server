# 控制台结构化配置表单

- 健康检测和 DNS 使用基础策略、可增删的探测档案、上游及有序路由表单。TLS、缓存和 Linux 捕获按需展开。
- 供应商和标准订阅使用连接、鉴权、参数、响应映射及补池表单。凭据字段默认隐藏，保留服务端脱敏标记和订阅快照。
- 分组和规则分开编辑全局策略和单条记录。成员、标签、动作、匹配条件及路由模拟用对应的输入控件。保留现有顺序、候选发布和版本冲突处理。
- 规则文件和订阅文档继续通过专用入口导入。配置工作台继续支持整份 TOML 草稿、比较、导入和导出。
- 对照 Rust 配置结构校验表单字段及默认值。使用隔离 Daemon 测试新增、修改、嵌套列表和保存冲突，检查桌面与窄屏布局。
