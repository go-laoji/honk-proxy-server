# T18 历史观测、诊断与任务实施计划

对应 #23，分支 `feature/observability-history`，依赖的 T17 已独立 finish。保持 Rust 后端、CLI/Daemon 独立、共享 React/Tailwind MPA 和无帐号直接访问；禁止宿主 Mac 网络写入。上一阶段发行产物已冻结，停止未完成的 x86 试验编译并保留依赖缓存，防止编译期间读取本阶段的新源码而误标来源；最终版本冻结后重建。

## 交付顺序

1. DASH-05 / CONN-05：以当前 Daemon epoch 的真实累计计数按固定间隔采样，保存有界一小时环形窗口，报告实际窗口、采样精度、重启边界和丢失/截断。连接关联只聚合元数据（来源/入口/目标/规则），不存业务正文；不把采样近似称为完整审计。
2. HEALTH-06 / NODE-07：查询已持久化的真实健康运行历史和现有探测预算；可选探测 plain IP 响应提供实际出口地址，严格限制响应大小和时间、标明来源与检测时刻；未配置时 IP/地域明确未知，不能从节点名或供应商地址推断。旧结果 JSON 向后兼容，不增加默认外部探测。
3. DNS-05 / RULE-07：扩展真实 DNS 命中/未命中和未过期名称映射诊断（来源/TTL/容量可见）；真实业务路由命中计数与模拟分开。规则 JSON 使用格式版本，导入先校验/预览/checksum，再创建候选；仍需显式激活。
4. LOG-05 / LOG-06：只导出白名单 DTO（版本、能力/资源、错误码、聚合），默认不含完整连接地址、URL、凭据或正文；同页预览再导出。以真实异常状态变化/恢复生成有界通知，限频和抑制计数可见；本阶段渠道为控制台/CLI，桌面系统通知由 T20 接续，不主动发送外部消息。
5. TASK-05：只为服务明确声明的只读诊断支持取消和重试，使用 epoch + version CAS、精确任务归属、停止令牌和有界重试输入；已提交配置/供应商购买不可取消且不自动重放，不伪造回滚。重试产生新 task 并关联旧 task，失败/过期阶段有明确理由。
6. 补齐 API、typed client、CLI、原生 bridge 路径、共享页面和导出。每片及时提交，围绕真实流量、时间窗口/上限、出口地址、脱敏、状态变化限频、CAS/取消竞争和规则候选不自动生效做回归；最后运行 workspace/Clippy、前端类型/格式/构建、Native 与浏览器测试，记录证据后回复关闭 Issue 并顺序 finish。

## 边界

运行态趋势不伪装成跨重启数据库历史，准确计数与有限采样摘要分别标识。健康持久历史遵守已有保留上限，不收集业务正文。地域未知是合法事实，不调用未经配置的第三方画像服务。告警规则属于运行配置并可停用，通知不引入用户身份或权限系统。macOS 系统代理持久写入/付费供应商实测的既有未验收项保持原状态；本项不把它们改为通过。
