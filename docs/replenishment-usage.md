# 自动补池、水位和预算

对应 [T07 / Issue #12](https://github.com/go-laoji/honk-proxy-server/issues/12)。每来源一个控制器，由 Daemon 后台循环驱动，代理请求不会同步等待供应商 API。全部可达使用者可查看和操作，不要求账号。

## 配置与语义

在供应商 JSON 编辑器使用“加入补池配置模板”，检查参数并保存，或参考 [通用接口 TOML](../configs/providers/json-api.example.toml)。自动补池默认停用，需要同时启用来源和 `refill.enabled`。

- `mode=on_demand` 为默认模式：存在该来源可服务的真实代理拨号或仍存活的代理出站工作时维护库存，超过 idle_timeout_secs 后停止补充。需求遵循入口/规则选定的组、来源、来源标签和代理协议。明确直连、拒绝、指定单个节点、严格固定或仅有静态成员的组不触发无关提取；固定租约的 ID 也不会因为重新购买而变成新 ID。需求按供应商指纹和路由/分组/入口策略指纹隔离，策略变化后不沿用旧购买信号。只连接入口端口、未发出有效代理目标请求的握手不触发购买。空池请求会先返回不可用，后台在下一轮补充；没有隐式直连。
- `mode=maintain` 显式持续维护库存，即使没有代理流量也会补充，仍受预算与冷却限制。
- 低于 min_nodes 时进入补充状态，分批补到 target_nodes；不会达到最小水位便提前停止。max_nodes 限制可准入库存，已退休租约和已有连接单独保留。
- retire_before_secs 与来源/全局最小剩余寿命共同限制准入，forecast_secs 计算预测窗口后的库存。按来源、协议端点和配置指纹去重；地域由该来源的提取参数约束，不把不同来源的库存混算。
- 批量最多为 batch_size、来源 count、目标缺口、最大水位余量和剩余节点预算中的最小值。在途请求占库存及预算，不重复下单。

通用 JSON/文本来源启用自动补池必须配置 **count_parameter**，例如供应商数量参数名为 num。Daemon 将实际计划数量写入该参数，不能只在本地修改解析上限。该名称必须按供应商文档确认；快代理固定使用 num，免费 HTML 来源按计划数量限制入库，不声称存在供应商租约保证。

最大水位等于目标水位时，可能没有预填充空间；界面会显示 watermark_capacity，等待租约退休后再评估。已知固定 TTL 必须大于退休及预测窗口，否则拒绝配置。实际返回寿命不足时拒收并暂停，避免持续购买不可准入的短租约。

健康默认启用，已准入库存要求期限、配置和新鲜可达证据均合格；待检测租约单独显示并保留补池名额，详见 [健康与补池协作](health-usage.md)。持续维护并不保证在预算不足、供应商失败或尚未健康时仍可转发。

## 统一预算与恢复

`daily_request_budget` 与 `daily_node_budget` 按来源 ID 和 **UTC 日期**计算，手动和自动提取共用；同一供应商的不同来源不自动合并为一个账户预算。升级时从保留的旧任务回填，已经清理的旧记录无法推算。SQLite 在受理事务中预留一次请求及请求的节点数；在途、失败和结果不确定均保守占用，不以收到较少节点推断供应商实际少扣费。任务历史清理、Daemon 重启、暂停/恢复、来源删除后重新使用同一 ID 都不会重置当日账本。时钟回拨不能回到较早预算周期。

暂停所有提取不会取消已经发出的请求，也不关闭现有代理连接。传输/响应丢失、损坏结果等 outcome_unknown 会暂停，需核对供应商记录后显式恢复。恢复保留预算、最小间隔与 Retry-After。确认只属于当时已结束的任务，不会确认仍在进行的请求或下一个任务；进程中断后的新不确定结果仍要求处理。

HTTP 429 作为明确限流拒绝，记录秒数或 HTTP 日期格式的 Retry-After，并进行有界退避；HTTP 库本身仍不重试。空结果按有界指数退避及小幅抖动处理，连续失败到 failure_limit 后暂停。额度用尽、鉴权、白名单、订单问题或寿命不足会暂停，不假设供应商额度会在本地 UTC 换日自动恢复。控制器不修改供应商白名单、订单或套餐。

## CLI 与控制台

```sh
hps provider controller json-api
hps provider evaluate json-api
hps provider pause json-api
# 核对上次结果后恢复；不清空预算和冷却
hps provider resume json-api
```

`evaluate` 只进行一次评估，可显式唤起按需策略，仍检查自动策略启用、暂停、预算、冷却和最大水位，返回实际任务或不执行原因。它不把整轮补池当作同步成功。控制台详情展示准入/预测/在途库存、UTC 使用量和重置时刻、下次允许时间、实际决策与暂停原因，后台新任务会同步到页面；切页取消读取，不取消已受理提取。

对应 API：GET `/api/v1/providers/{id}/controller`，POST 同路径下的 `/evaluate`、`/pause`、`/resume`。预算耗尽返回 429，暂停或时钟回拨返回 409，客户端不自动重放提取。
