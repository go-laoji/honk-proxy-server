# 按目标配置代理组分流

对应 [Issue #49](https://github.com/go-laoji/honk-proxy-server/issues/49)，基于 `feature/provider-region-groups`。参考 Doona 的 [从连接带入目标并选择出站](https://github.com/Zakkaus/doona/blob/dcfa505700179e15f8bb37c82e04135f18119c5d/e2e/quick-rule.spec.ts) 交互。

- 复用现有首条命中的路由引擎、目标组准入、候选版本和显式激活。规则接口提供与运行版本对应的目标组 ID，普通规则和默认动作使用组选择框。
- 规则页提供按完整域名、域名后缀、目标 IP 或 CIDR 创建规则的简表单。可加目标端口和传输限制，选择首位或末尾。连接详情带入实际目标，分组页带入组名。保存后将目标带到模拟表单，可检查实际命中规则和组选点，再激活候选。
- 使用两个回环上游验证不同条件转发至不同组、候选激活前后效果、组或连接入口带值、旧规则编辑和默认动作。保持宿主网络保护变量，服务仅使用回环地址与隔离状态。
