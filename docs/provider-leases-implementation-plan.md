# T06 短效供应商与租约实施计划

对应 [Issue #11](https://github.com/go-laoji/honk-proxy-server/issues/11)。前置配置版本已完成，继续采用全 Rust、独立 CLI/Daemon、共享 React/Tailwind MPA，无登录、账号或操作权限模型。

## 契约与交付切片

1. 来源配置进入不可变配置版本，支持启停、删除、参数、请求头、抓取出口、超时、数量/地域和上游认证；API/导出/Debug 不泄漏供应商密钥。快代理实现 token 与 HMAC-SHA1，通用 JSON 与文本接口用于其他供应商；云代理是独立 HTML 免费源适配器。
2. schema 3 单独存储提取任务、批次和租约。提取任务先持久受理再发请求；同来源合并在途触发，请求 ID 去重。任何可能已消耗额度的网络失败保留 outcome_unknown，禁用 HTTP 库隐式重试和重定向，不自动重放。
3. 增量来源默认 append_leases；replace_snapshot 需要明确声明全量契约与最小结果保护。空响应、格式错误或异常缩减保留旧池。每次新提取产生独立租约，绝不按重复 IP 延长旧租约。供应商停用/删除立即阻止新提取与新连接选择，已有连接不承诺迁移。
4. 持久结果发布给共享动态池，不为每批提取制造配置版本。租约记录来源/配置指纹/批次、开始/接收/绝对到期和期限依据；配置改变时只允许相同指纹来源的结果参与当前选点，避免旧请求跨配置发布。
5. API/CLI 与两个 MPA 页面提供来源清单/编辑入口、手动提取任务、批次/租约分页、结果和只读诊断；Desktop 使用相同 DTO/页面与 allowlist。自动补池、健康与统一任务事件分别在 T07/T08/T14 接续。

## 供应商与有效期

- [快代理 getdps](https://www.kuaidaili.com/doc/api/getdps/) 使用订单密钥、JSON 响应。签名严格按 [官方授权说明](https://www.kuaidaili.com/doc/api/auth/) 的原值排序、方法/路径和 HMAC-SHA1 计算，再编码一次。
- 到期可从 [getdpsvalidtime](https://www.kuaidaili.com/doc/api/getdpsvalidtime/) 的秒数归一化；部分订单不支持此接口，此时必须显式配置订单保证的保守 TTL，起算点为本次提取请求开始，不能用收到响应时间延期。未采购时不猜测订单寿命或使用虚构 API 密钥调用付费接口。
- 通用 JSON 通过显式 JSON Pointer 取列表、主机/端口及 TTL/绝对到期字段；单位仅接受明确秒/毫秒。文本来源必须有保守 TTL。无到期信息不自动视为永久节点。
- [云代理免费列表](http://www.ip3366.net/free/?stype=1) 未承诺节点租约，以用户配置的缓存上限作为本地退休时间，并明确显示“本地缓存上限，非供应商保证”。HTTPS 目标支持不等于代理入口本身使用 TLS；列表 HTTP/HTTPS 标签按 HTTP CONNECT 代理解析。

## 验证门槛

签名固定向量、字段解析/IPv6/时间单位、短寿命拒收、连续批次不误删、快照缩减保护、重复端点独立租约、旧请求跨配置隔离、并发/重复触发、客户端离开继续、响应丢失不重试、429/鉴权/白名单/额度分类、重启中断标记与凭据脱敏均需覆盖。实际免费页面获取/解析与节点健康分开报告。用户明确允许按官方文档实现快代理，无付费采购；付费端到端调用保持“未验证”，不阻塞文档契约交付，也不声称已通过付费验收。
