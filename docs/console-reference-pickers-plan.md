# 控制台引用选择优化

对应 [Issue #52](https://github.com/go-laoji/honk-proxy-server/issues/52)。

1. 复用 Daemon 的节点、入口、供应商和订阅 API。小列表用原生下拉；节点只载入首批，按需搜索 ID、地址或地区。列表失败与空结果分别提示，保留已保存但当前列表未返回的值。
2. 分组编辑的成员、来源、子组、固定、回退和权重，以及选择策略的默认组、入口绑定和标签改用选择控件。分组详情的固定/回退仅列出组成员；回退顺序可调整。新建分组 ID 仍为文本。
3. 规则动作选择节点或分组，切换动作清空上一种目标。规则匹配条件和分组/规则模拟从当前入口中选择。历史日志筛选保留手填，以便查找已删除对象。
4. 按现有浏览器规格验证保存后仍提交 ID、键盘操作、重复选择、空配置和移动宽度；构建与类型检查使用共享 React 产物。不修改宿主网络。
