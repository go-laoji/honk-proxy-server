# 控制台配色与轻动效计划（#27）

为共享 React/Tailwind 18 页 MPA 建立克制、易读的颜色层次。沿用现有业务结构、API 和主题切换，浅色与深色统一设计。 按用户在并行 Logo 评审的最新反馈，最终方向调整为冷蓝科技风；以已确认 `brand-visual-direction-v2.png` 的 LIGHT 区域为参考：近冷白侧栏、整行浅蓝选中态、细蓝卡片/图表边界与轻面积填充。Logo 图形和资源由独立任务集成，本分支不改品牌节点或图标资源。

| 用途 | 设计方向 |
| --- | --- |
| 品牌与主要操作 | 钴蓝 #2563EB，hover #1D4ED8；深色强调 #60A5FA |
| 辅助信息 | 亮蓝 #38BDF8，仅用于少量深色图表/图标；浅色曲线用 #0284C7 保证对比 |
| 页面/面板 | 冷白 #F4F7FC、白卡；深色午夜蓝 #0B1220、面板 #111C30、边界 #24334D |
| 语义状态 | 青绿成功、琥珀警告、玫红错误；始终保留文字和形状，不只依赖颜色 |
| 指标/图表 | 小面积蓝色图标块与精确边线；下载钴蓝、上传亮蓝、失败琥珀，绿色仅作成功状态 |

实施按阶段提交：计划、主题与共享组件、轻动效、用户反馈调整、浏览器验证记录。图标优先在 wrapper 上做 transform，导航 hover 小幅位移/转角，只有加载中旋转；无整页入场、持续装饰动画或新动画依赖。`prefers-reduced-motion` 停用非必要动画，保留可读加载文字。键盘 focus、disabled、hover 和两种主题都要明确。

验收使用 macOS 本机已有工具：类型、格式、18 页生产构建；现有浏览器回归与真实界面截图检查（宽屏/移动、浅/深色、reduced motion）。不启动 x86/Docker，不修改 Mac 网络，不运行旧 ignored 网络测试或覆盖用户原 Desktop bundle。界面变动不要求重复后端整套测试或重新打跨平台发行包。

从当前 develop 通过 `git flow feature start console-color-motion` 开始，小步提交。开发完成回复真实证据到 #27 再关闭；本次保留 feature，不主动 finish/push/合入 main。
