# 控制台配色与轻动效计划（#27）

为共享 React/Tailwind 18 页 MPA 建立克制、易读的颜色层次。沿用现有业务结构、API 和主题切换，浅色与深色统一设计。

| 用途 | 设计方向 |
| --- | --- |
| 品牌与主要操作 | 松石青；浅色主色 #14786c，深色浅青强调 |
| 辅助信息 | 低饱和雾蓝；链接、部分指标、上传曲线 |
| 页面/面板 | 冷灰背景、白色卡片；深色使用带蓝的墨色，边界保持可辨 |
| 语义状态 | 青绿成功、琥珀警告、玫红错误；始终保留文字和形状，不只依赖颜色 |
| 指标/图表 | 小面积色块与边线；下载青、上传蓝、失败琥珀，禁止虚构活动状态 |

实施分三笔提交：先保存计划；再提交主题 token、共享布局/组件和指标/图表配色；最后补充必要的动效与浏览器验证记录。图标优先在 wrapper 上做 transform，导航 hover 小幅位移/转角，只有加载中旋转；无整页入场、持续装饰动画或新动画依赖。`prefers-reduced-motion` 停用非必要动画，保留可读加载文字。键盘 focus、disabled、hover 和两种主题都要明确。

验收使用 macOS 本机已有工具：类型、格式、18 页生产构建；现有浏览器回归与真实界面截图检查（宽屏/移动、浅/深色、reduced motion）。不启动 x86/Docker，不修改 Mac 网络，不运行旧 ignored 网络测试或覆盖用户原 Desktop bundle。界面变动不要求重复后端整套测试或重新打跨平台发行包。

从当前 develop 通过 `git flow feature start console-color-motion` 开始，小步提交。开发完成回复真实证据到 #27 再关闭；本次保留 feature，不主动 finish/push/合入 main。
