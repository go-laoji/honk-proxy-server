## CLI 与 Desktop 实际操作

独立本地探测目标/HTTP 代理与 `hpsd` 实例在 `127.0.0.1:17992` 验收。实际 Desktop 窗口通过原生桥连接该实例：显示 1/1 可准入，触发手动 `health:2`，窗口和 CLI 均确认 completed、healthy=1；展开状态显示 IPv4 成功、IPv6 未配置、UDP unsupported。通过同一页面把周期改为 90 秒，服务实际应用到 r2。

独立 CLI 又以固定 request_id 发出并重复查询探测，实际新增预留仅一次，任务 ID 相同。CLI 保存策略到 r3 成功，旧 expected_revision 再次保存退出码为 7。全过程没有图形会话依赖、没有调用付费供应商或改变系统代理。

验收后停止了独立目标/代理/Daemon，Desktop 已恢复连接项目 `127.0.0.1:17900` 预览。最终 .app 重新打开并确认健康页、从同一运行快照读取的 r1 编辑器均可用，取消编辑后保留预览。项目预览使用明确停用健康的空测试配置，不展示伪造节点。
