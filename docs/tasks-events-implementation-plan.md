# T14 后台任务、结构化事件与 SSE 实施计划

对应 [Issue #19](https://github.com/go-laoji/honk-proxy-server/issues/19)，分支 `feature/tasks-events`，基于 T13。使用现有 Rust/SQLite 单写者、Daemon 任务所有权与 React/Tailwind MPA，不引入账号、登录、权限或已认证操作人。

## 当前路径与要补齐的问题

供应商提取和健康任务已持久化，分别保留计费结果不确定、并发合并与实际进度；配置激活也有持久历史。它们缺少统一查询与事件流。`create_revision` 当前在请求 future 内持有操作锁并等待 blocking 预检，客户端离开会提前释放该锁；部分诊断虽保持 CPU 许可，却没有统一终态和关闭等待。激活的 detached task 也需要纳入服务任务追踪，避免关闭时遗漏。现有 tasks/events 页面仍是基础能力占位。

## 分批交付

1. **持久任务和事件契约**：迁移 0008 建立统一任务投影、单调版本和结构化事件。供应商、健康、配置激活的实际状态在同一 SQLite 事务内更新投影并产生事件，避免重新解释计费/探测结果或读取请求消失后漏终态。导入既有记录；通用预检/诊断持久记录通过单写者更新。全部 ID、状态、阶段、数量、版本、时间与错误类别有明确上限。
2. **工作所有权和重复触发**：配置预检/激活与实际诊断由服务持有任务，受固定容量控制，在关闭互斥边界内注册到 TaskTracker。调用方离开只取消等待，不丢已接受工作、不提前释放 blocking 容量；关闭等待工作终态。供应商沿用 request_id/预算，健康沿用实际合并，配置沿用版本 CAS；新异步提交使用 request_id 加输入指纹，重复返回已有任务，改变输入返回冲突。不对提取异常自动购买或重放。
3. **查询和管理操作事件**：统一任务列表/详情、状态/种类/资源/时间过滤与有界分页。结构化事件按级别、模块、任务/请求 ID、节点、来源与时间检索。管理写操作记录实际连接来源（未知则明确为空）、目标实例/资源、动作和结果；不记录请求体、完整 URL/查询、供应商 token、认证头、配置备注或业务数据，不声称识别操作人。
4. **事件游标与 SSE**：每次服务启动的观测 epoch 与单调事件序号组成游标。读取先取得有界快照和游标，再流式跟踪；过滤也推进已扫描游标。缓存/历史窗口过期或 epoch 变化返回明确 reset，客户端补快照，不把旧实例事件并入新目标。服务端限制连接数、每批条数和历史保留，慢消费者不能导致无界队列，断连及时释放订阅。
5. **CLI / 共享 MPA / Native**：typed client 和 CLI 查询任务、恢复 request_id、查询/跟踪事件；`tasks.html` 与 `events.html` 支持直接 URL、筛选恢复、任务详情链接、暂停、连接状态及恢复。浏览器同源 SSE；Native 仅订阅固定事件接口，目标切换/页面卸载显式取消，晚到事件需核对订阅代际和 epoch。共用同一 UI 与 DTO。
6. **验证与文档**：真实本地提取服务、探测、配置预检和激活，客户端中断后查询同一终态；重复触发与异输入冲突、重启恢复、慢订阅/游标淘汰/过滤无命中、实例切换、原生取消及凭据脱敏。macOS/Linux、API/CLI、浏览器和独立原生包逐批验证并提交，回复 Issue 后再关闭。

## 一致性、隐私和资源边界

- 统一投影保留原始来源引用、任务实际配置版本或指纹，未知旧版本明确为空，不用当前配置冒充历史。失败、跳过、结果不确定、等待重启与中断分别呈现；健康任务完成不等于所有节点健康。
- 事件和任务投影在同一源状态事务中生成，不依赖浏览器轮询来补写。SSE 传输从有界持久日志读取，使用容量许可，避免每个订阅者复制无限历史。
- 通用工作不能保存输入正文或凭据。输入指纹仅作幂等比较，结果仅允许有界、安全的诊断 DTO 或既有资源引用。所有错误为固定类别，不把供应商响应原文、TLS/URL 错误堆栈直接传给正常事件。
- 接受工作不等于可以撤销。T14 先查询和恢复；只有后续 T18 为实际支持的阶段声明取消/重试能力，不能把已经提交的配置或已付费提取假称回滚。
- T14 任务和事件按固定条数保留，分页、订阅数量及工作槽位在代码与使用文档中一致声明；历史年龄策略留给 T18，不把已有 retention.task_days/activity_days 配置冒称为本轮已执行。终态淘汰明确返回不可用；游标淘汰补快照，不默默跳过并假装完整。
- 本任务不将日志或 DNS 已挂载状态当作完整 Linux 数据面就绪，T15 继续使用真实内核验证。
